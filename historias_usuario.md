-- HU-01. Registro de usuario

Historia de usuario:
Como aprendiz nuevo, quiero crear una cuenta con mi correo o número telefónico y contraseña para acceder y unirme a clases de mi formación.

Condición para considerarla terminada:
El sistema cuenta con un formulario de registro que permite ingresar el correo o número telefónico, la contraseña, valida los campos obligatorios y confirma que la cuenta fue creada correctamente.


-- HU-02. Inicio de sesión

Historia de usuario:
Como aprendiz, quiero iniciar sesión con mi correo institucional y contraseña para que mi información esté segura.

Condición para considerarla terminada:
El sistema dispone de una pantalla de inicio de sesión que valida el correo institucional y la contraseña, permitiendo el acceso al usuario.



-- HU-03. Notificaciones de seguridad

Historia de usuario:
Como aprendiz, quiero recibir notificaciones de seguridad para mantenerme al tanto si alguien intentó ingresar a mi cuenta.

Condición para considerarla terminada:
El sistema envía o muestra una notificación cuando detecta un intento de acceso no autorizado a la cuenta del usuario.



-- HU-04. Notificaciones de actualización

Historia de usuario:
Como aprendiz, quiero recibir notificaciones de actualización de la aplicación para mantenerme al tanto de las nuevas funciones.

Condición para considerarla terminada:
El sistema informa al usuario cuando existe una nueva versión o actualización disponible de la aplicación.



-- HU-05. Cambio de tema

Historia de usuario:
Como aprendiz, quiero modificar el tema de la aplicación a claro, oscuro o predeterminado para mejorar el diseño visual.

Condición para considerarla terminada:
El usuario puede seleccionar el tema deseado desde la configuración y el cambio se aplica correctamente en toda la interfaz.




-- HU-06. Edición del perfil del aprendiz

Historia de usuario:
Como aprendiz, quiero editar mi perfil para actualizar mi información personal y foto de perfil.

Condición para considerarla terminada:
El usuario puede modificar sus datos personales, cambiar su foto de perfil y guardar los cambios correctamente.



-- HU-07. Edición del perfil del instructor

Historia de usuario:
Como instructor, quiero editar y actualizar mi perfil para mantener mis datos actualizados.

Condición para considerarla terminada:
El instructor puede actualizar su información personal y guardar los cambios para que se reflejen en su perfil.



-- HU-08. Visualización de actividades pendientes

Historia de usuario:
Como aprendiz, quiero que al inicio se vean mis actividades pendientes para reconocerlas de forma inmediata.

Condición para considerarla terminada:
Al iniciar sesión, el sistema muestra un listado de las actividades pendientes del aprendiz.



-- HU-09. Orden de actividades

Historia de usuario:
Como aprendiz, quiero que las actividades se vean ordenadas por fecha de entrega para planificación.

Condición para considerarla terminada:
El sistema organiza automáticamente las actividades según la fecha de entrega, mostrando primero las más próximas a vencer.



-- HU-10. Información de la actividad

Historia de usuario:
Como aprendiz, quiero ver el título y la competencia para conocer de qué trata la actividad.

Condición para considerarla terminada:
Cada actividad muestra claramente el título y la competencia a la que pertenece.



-- HU-11. Detalle de la actividad

Historia de usuario:
Como aprendiz, quiero abrir estas actividades para ver la descripción de esta y archivos adjuntos.

Condición para considerarla terminada:
Al seleccionar una actividad, el sistema muestra la descripción completa y permite visualizar o descargar los archivos adjuntos disponibles.
